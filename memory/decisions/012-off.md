## Context / Forces

The refactor scan tooling supports a Figma-plugin extraction mode, but the project has no Figma plugin source and the scan reported `figma.detected=false`, so enabling the mode would only have added empty output.

## Decision

The Figma plugin scan mode stays off for app/site scans. Follow this rule for future work on `app/site`.

## Alternatives

| Option | Why rejected |
| --- | --- |
| Running the Figma pass anyway was rejected as dead work: there is no Figma plugin in this repo to analyze. |

## Consequences

Future scans of this repo can skip the Figma mode unless a plugin is actually added; if one appears, revisit this. (*Origin:* `refactor-app-site/decisions/02`)
