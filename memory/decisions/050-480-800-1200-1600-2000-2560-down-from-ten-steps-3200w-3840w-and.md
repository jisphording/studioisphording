## Context / Forces

The old width table ran to 4320w at quality 99 for a two-column grid (`RES-06`). 2560 is kept rather than stopping at 2000 because `.showreel img { scale: 1.4 }` and `.showcase__grid--item:hover img { scale: 1.1 }` render images larger than their box (`dev/css/templates/_projects-showcase.scss`). The hover zoom must not go soft.

Citation: `03-media-compression-and-delivery/decisions/12`

## Decision

The width table is 480 / 800 / 1200 / 1600 / 2000 / 2560. The 3200w, 3840w and 4320w steps are dropped.

## Alternatives

| Option | Why rejected |
| --- | --- |
| Stop at 2000 | The CSS scale-ups would render soft. |
| Keep the ten-step table | Large steps are wasted bytes for the layout. |

## Consequences

Fewer derivatives to encode, store and deploy. Revisiting is needed if the layouts or the CSS scale factors grow.
